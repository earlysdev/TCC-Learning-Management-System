📥 Import Quiz from CSV / Excel

STEP 1 — CHOOSE YOUR FILE

Upload a .csv (Excel CSV) or .xlsx (Excel Workbook) file. The quiz will open in the quiz builder for you to review before publishing.

STEP 2 — FILE STRUCTURE (3 PARTS)

Row 1 The Quiz Title — type it in the very first cell (Column A only). Row 2 The Column Headers — copy-paste these exactly: type, question, optionA, optionB, optionC, optionD, correctAnswer, points Row 3+ Each row = one question. Add as many rows as you need.

STEP 3 — QUESTION TYPES & HOW TO FILL THEM

Type (Column A) Options A–D Correct Answer (Column G)
multiple-choice Fill in your 4 choices Write the letter of the correct choice: A, B, C, or D
multiple-selection Fill in your choices Letters separated by comma, no spaces: A,C or B,D
true-false Leave all blank Write exactly true or false (all lowercase)
identification Leave all blank Type the expected answer (e.g., Photosynthesis or H2O)
essay Leave all blank Optional: write a model/sample answer for teacher reference only

⚠️ IMPORTANT REMINDERS

  • The type must be spelled exactly as shown above — all lowercase with hyphens.
  • For multiple-selection, write letters with no spaces: A,C not A, C
  • If a question text contains a comma, wrap it in quotes in Excel: "Which are mammals, birds, or fish?"
  • Do NOT add extra rows or columns before the quiz title.
